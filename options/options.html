Before Loot Captain starts

Loot Captain stores character names, profiles, item names, and stats in this browser. It reads item data from visited RaidLoot and OpenDKP pages to show local comparisons.

When you import or enrich gear, public item/profile data may be requested from RaidLoot. No login cookies, account data, analytics, or tracking are used.

Add Character

Paste a RaidLoot profile URL or its numeric profile ID. This imports the worn items, their stats, and the public RaidLoot wishlist into this character. The wishlist import is one-way and does not remove local entries.

In-game, run /output inventory. This saves a file named [name]_[server]-Inventory.txt to your EQ folder. Select it below to create a character from your worn equipment. The export contains item data and the character name comes from the filename; class and level must be entered manually or imported from a RaidLoot profile.
