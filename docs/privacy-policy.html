Data use and retention

Privacy Policy

Effective date: August 22, 2026

Loot Captain is a local-first browser extension for comparing EverQuest gear. This policy explains what the extension stores and what network requests it makes.

Data handled

The extension stores the following in browser-local chrome.storage.local:

  • Character/profile names, class, level, equipment slots, item IDs, item names, and item stats entered or imported by the user.
  • The selected character and score formula.
  • Imported profile data and fetched public RaidLoot item stats used in comparisons.

Loot Captain does not collect email addresses, passwords, payment information, precise location, browsing history, analytics identifiers, or advertising identifiers. Character and item names are retained locally and may be sent to RaidLoot only when an item lookup is needed.

When a comparison is displayed, the extension renders relevant worn-item and candidate-item names, badges, and stat differences into the DOM of the visited RaidLoot or OpenDKP page. This is local page rendering, not collection of browsing history.

Network use

When the user imports a profile or a profile/comparison needs missing stats, Loot Captain fetches public pages from raidloot.com for profile and item information. An OpenDKP item name may be sent automatically to RaidLoot for an exact-name lookup. Requests do not include authenticated browser credentials or cookies.

On OpenDKP pages, the extension reads visible item UI and page item-data responses to add a local comparison badge. That data is not sent to an OpenDKP server by the extension.

Sharing and sale

Loot Captain does not sell, rent, or share user data with advertisers, data brokers, or other third parties except for the public RaidLoot lookup needed to provide the comparison described above. It has no analytics or tracking service.

Limited Use

Loot Captain uses profile, item, and page data only to provide its single purpose: local EverQuest gear comparison on the current page. It complies with the Chrome Web Store User Data Policy and its Limited Use requirements. It does not use data for advertising, credit, insurance, lending, price discrimination, or unrelated personalization.

Retention and deletion

Local data remains in extension storage until the user deletes a profile, clears extension storage, or uninstalls the extension. Fetched public item stats may be refreshed or replaced automatically.

Security and changes

The extension uses minimum declared permissions for local storage, public RaidLoot fetching, and local HTML parsing. It does not execute remotely hosted code. Policy changes will be published with a new extension release and reflected in the effective date.

Contact

For privacy questions, visit Loot Captain support. Do not include personal or sensitive information in a public issue.
