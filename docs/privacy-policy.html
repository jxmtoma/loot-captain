Loot Captain Privacy Policy

Effective date: August 22, 2026

Loot Captain is a local-first browser extension for comparing EverQuest gear. It stores character/profile names, class, level, equipment slots, item IDs, item names, item stats, the selected character, score formula, and fetched public RaidLoot item stats in browser-local chrome.storage.local.

It does not collect email addresses, passwords, payment information, precise location, browsing history, analytics identifiers, or advertising identifiers. Character and item names may be sent automatically to RaidLoot when an import or comparison needs a missing stat, including an exact-name lookup for an OpenDKP item. Requests do not include authenticated cookies.

On RaidLoot and OpenDKP pages, the extension reads current item content locally and renders worn-item names, candidate-item names, badges, and stat differences into the visited-page DOM. It does not send that page data to an OpenDKP server.

Limited Use

Data is used only to provide local EverQuest gear comparison on the current page. Loot Captain complies with the Chrome Web Store User Data Policy and its Limited Use requirements. It does not sell or share data with advertisers or data brokers and does not use it for advertising, credit, insurance, lending, price discrimination, or unrelated personalization.

Retention and deletion

Local data remains until the user deletes a profile, clears extension storage, or uninstalls the extension. Fetched public item stats may be refreshed or replaced automatically.

Security and changes

The extension uses local storage, public RaidLoot fetching, and local HTML parsing. It does not execute remotely hosted code. Policy changes will be published with a new extension release.

Contact

For privacy questions, use the support contact published with the Chrome Web Store listing.
