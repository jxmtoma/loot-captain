Help and feedback

Support

Loot Captain supports current Chrome and Edge releases on RaidLoot and OpenDKP.

Quick checks

  1. Open Manage Characters from the extension and accept the data-use disclosure.
  2. Create or import a character, then mark it as active.
  3. Reload the RaidLoot or OpenDKP tab after installing or updating the extension.
  4. If an item shows ?, open the profile again so Loot Captain can retry missing public stats.

Report a problem

Open a GitHub issue and include:

  • Whether the problem occurred on RaidLoot or OpenDKP.
  • The page type, such as an item page, auction list, or tooltip.
  • What you expected and what happened instead.
  • Your browser and Loot Captain version.
Please do not post passwords, cookies, private account information, or other sensitive data.

Feature requests

Feature ideas are welcome in the GitHub issue tracker. Include the gameplay problem you want to solve and an example of the desired result.

Known behavior

  • The first missing-stat lookup can take a few seconds.
  • An unmatched item may show ? until its stats are available from RaidLoot or entered manually.
  • OpenDKP layouts vary by guild, so include the affected page type when reporting a display problem.

Remove local data

Delete individual characters from Manage Characters. Uninstalling Loot Captain removes its extension-local profiles, settings, and fetched item stats from the browser.

Privacy questions

Review the privacy policy. If your question is not answered there, open a GitHub issue without including personal or sensitive information.
